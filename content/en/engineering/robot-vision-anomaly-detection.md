This project combines robot vision and image anomaly detection for inspection. The focus was turning model outputs into traceable, testable, and integrable engineering workflows.

## Robot Vision

- Used RealSense, OpenCV, and AprilTag for robot image acquisition, localization, and physical-task perception.
- Integrated visual results with robot-control workflows and repeatable task validation.

## Anomaly Detection

- Developed a PatchCore API server and PyQt interface.
- Integrated image preprocessing, anomaly detection, and result analysis.

The PatchCore implementation provides a traceable, integrable AI inspection workflow.
