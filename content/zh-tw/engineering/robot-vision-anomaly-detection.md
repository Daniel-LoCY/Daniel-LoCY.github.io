此專案整合機器人視覺與影像異常檢測，重點是將模型輸出轉成可追蹤、可測試、可整合的工程流程。

## 機器人視覺

- 以 RealSense、OpenCV 與 AprilTag 支援機器人影像取得、定位與真機感知流程。
- 將視覺結果與機器人控制流程整合，完成可重複的任務驗證。

## 異常檢測

- 開發 PatchCore API Server 與 PyQt 介面。
- 整合影像前處理、異常檢測與結果分析流程。

PatchCore 實作形成可追蹤、可整合的 AI 視覺檢測流程。
